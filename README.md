# سندس دي أنا — خطتي الصحية

تطبيق React/Vite عربي يعمل **أوفلاين بالكامل** داخل WebView محلي. لا يوجد حساب، ولا API، ولا قاعدة بيانات خارجية، ولا تحديث OTA أو تحميل من GitHub أثناء التشغيل.

## المزايا

- حفظ الوجبات، الإنجازات، الألعاب، الواجبات، الماء وروتين اليوم في `localStorage` على الجهاز.
- صفحة «ألعابي» تبدأ فارغة وتحتوي على **إضافة لعبة فقط**.
- عند إضافة لعبة يمكن اختيار صورة من الجهاز، وتُحفظ الصورة محليًا داخل بيانات اللعبة.
- صفحة «واجباتي» تبدأ فارغة وتحتوي على إضافة واجب، موعد، ملاحظات، تحديد الإنجاز، وحالة التنبيه.
- زر إشعارات محلي في الشريط العلوي، مع طلب إذن إشعارات Android عند تشغيل APK.
- صفحة «ذكائي اليومي» للصباح والمساء؛ اقتراحات وروتين محليان يعملان دون أي خدمة ذكاء اصطناعي خارجية.
- كل الصور والفيديوهات المستخدمة في التطبيق مضمّنة داخل حزمة الواجهة.

## التشغيل المحلي

```bash
npm ci
npm run typecheck
npm run build
```

## بناء APK محلي

يتطلب JDK 17+ وAndroid SDK API 35:

```bash
npm run build
cd android
./gradlew assembleDebug
```

ينتج APK في:

`android/app/build/outputs/apk/debug/app-debug.apk`
